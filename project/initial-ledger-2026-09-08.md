# 探索的な数学的発見 — プロジェクト説明と成果台帳

整理日：2026 09 08 ／ 第1版

## プロジェクトの説明

GPT-6 Astraの学習済みの数学知識から、「ここを深く考えると、まだ明示されていない命題・関係・証明が見つかりそうだ」と見込まれる領域を選び、人間とAIの協働で探索する研究プロジェクト。

AIが候補選定、定式化、計算実験、反例探索、証明、文献照合を担い、横田さんが研究の願いを示し、方向性や結論を監査する。得られた命題だけでなく、失敗した仮説、既知結果との一致、訂正の経緯を再利用できる形にまとめ、公開する。

ここでいう「事前分布」は、探索先に優先順位を付けるための作業上の言葉である。未知の定理の存在確率を測定できているという意味ではない。直感は候補を生み、証明と文献照合がその評価を更新する。

有名な未解決問題への挑戦と、小さくても独立した価値を持つ命題の探索を両立する。既知結果の再発見も出典を明示して蓄積し、その先に残る差分を調べる。成果の価値は、他の人が検証・応用・拡張できる知識を増やせたかで評価する。

## E01：小さな回路を更新する数学

[公開研究ノート：P vs NPを追いかける](https://nikki.yokoda.okinawa/works/p-vs-np-note/)

[紹介記事：2026 09 06](https://nikki.yokoda.okinawa/posts/2026/09/2026-09-06-001/)

真理値表を順番に読み、既読の出力を説明する小さな回路を、少ない記憶と速い更新で保持できるかを研究する。公開ノートは研究ノートv0.25／候補台帳v0.17を基礎とする。

回路の基底はfan-in 2のAND・ORとfan-in 1のNOTで、各ゲートを1と数える。入力線とfan-outは無料。以下の二構成は無料定数に依存しない。

### 証明を収録した成果候補

**C35：辞書順の次ビット変更。** n≥1、1≤i<2ⁿとし、w=popcount(i)とする。既読のi点を保存しながら、次の位置iを1にするには高々wゲート、0にするには高々w+1ゲートの追加で足りる。未読の他の位置は変更されてもよい。

したがって、既読列uに整合する最小回路サイズをτ(u)、許容サイズをsとすると、次値が0に強制されるにはs−τ(u)<wが必要であり、1に強制されるにはs−τ(u)<w+1が必要となる。これは必要条件である。

**C36：連続区間の変更。** n≥1、1≤k≤2ⁿ、0≤a≤2ⁿ−kとする。連続区間[a,a+k)のk個の出力を任意に指定し、区間外のすべての出力を保存する回路を、元の回路に高々3k+3n−3ゲート追加して構成できる。

これらは変更費用の上界である。繰り返し更新して常にサイズs以下に保つ方法や、任意の更新法に対する下界を与えるものではない。

### 記録された検証

| 検証 | 公開版の報告 |
| --- | --- |
| C35 | n=1〜4、全Boolean関数・全非空proper cut・両変更値の1,969,768ケース |
| C36 | n=1〜4、263,172回路・8,403,968評価行。追加でn=5,6,8,10の1,754回路 |
| 最小回路の列挙 | 7,493組のlive prefixと閾値。次値が強制された5,680組でC35の必要条件への違反0 |

有限検査に加えて一般の構成証明を掲載している。人間の専門家による査読、証明支援系による形式検証は未実施と明記されている。

### 既知結果との関係と残る課題

P=NPを仮定すれば所定の効率的な証人保持WCを構成できる、というC20は、McKay–Murray–Williamsの既知構成からの系として扱われている。C35・C36は初等的な構成であり、学術的新規性は未確認。

未解決なのは、所定のモデルで全ての一様な多項式資源のWCを排除する無条件の下界、およびSATからの入力生成と全ての小さな補完回路からの証人抽出などである。本研究ではP=NPもP≠NPも証明していない。

この柱で蓄積した訂正も成果として残す。特定の表現形式の下界から一般の計算時間下界へは直ちに移れず、特定の代表選択規則の困難性も全ての選択規則の困難性とは異なる。公開ノート末尾の訂正台帳を、次の候補評価でも参照する。

## E02：形が未知の分布を最適に代表する数学

[公開研究ノート：分布の「真ん中」を求める](https://nikki.yokoda.okinawa/works/wasserstein-center/)

[紹介記事：2026 09 06](https://nikki.yokoda.okinawa/posts/2026/09/2026-09-06-002/)

[0,1]内に値を取り、平均μと分散vが指定された全ての確率分布を考える。代表Qを一つ選び、その族の中でQから最も遠い分布までのWasserstein-2距離を最小化する。代表Q自体には入力と同じ分散を要求せず、有限二次モーメントを持つ任意の実数上の分布を許す。

### 証明を収録した成果候補

0<μ<1、0<v<M=μ(1−μ)とし、L=log(M/v)、κ=2/(2+L)と置く。

**定理A：一意な最適中心と最小半径。** 最適中心Cは一意で、最小半径Rは

\[
R^2=\frac{v\log(M/v)}{2+\log(M/v)}=v(1-\kappa)
\]

を満たす。中心の分位関数は、

\[
H(u)=\min\{\mu u,(1-\mu)(1-u),\sqrt{vu(1-u)}\},\qquad
f_C(u)=\mu-\kappa H'(u)
\]

でほとんど至る所明示できる。Cの平均はμ、分散はκv。非退化の場合には二つの点質量と連続部分を持ち、その間に空隙がある。v=0またはv=Mでは入力族が一つの分布に決まり、R=0となる。

**定理B：最遠入力の完全分類。** 非退化の場合、最悪距離Rを達成する入力は、指定の平均・分散を満たす二点分布、または支持が{0,c,1}に含まれる分布に限られ、これらは全て最悪距離を達成する。

**安定性の帰結。** 全入力に対する最悪二乗誤差がR²+ε以下の代表Qなら、W₂(Q,C)≤√εである。

### 既知の部品と、新規性が残る箇所

| 対象 | 公開版の文献照合結果 |
| --- | --- |
| 補助分布Sの形 | Stoyan（1973）定理3と一致。再発見として帰属 |
| Sの対数を含む分散公式 | Hürlimann（1996）式(2.4)と一致 |
| 指数核・両端原子と一様密度の重み | 既知の構造として扱う |
| Sを平均の周りに最適縮小したCが、全入力族の一意なW₂中心になること | 調査した一次資料では同一結果を未確認 |
| 最遠入力の必要十分条件 | 同じ完全分類を未確認 |

上の帰属は今回改めて先行論文を全面再読した判定ではなく、公開研究ノートの照合報告を引き継いだものである。未読文献・別表現・被引用文献の追跡が残るため、新規性は未確定とする。

### 記録された検証と残る課題

格子上12,870分布と固定seedの2,000分布、合計14,870分布を検査。51,791切点の包絡・モーメント確認と、別方式の数値積分も報告されている。各入力はそれぞれ自身の平均・分散に対応する中心で検査されており、一つの固定モーメント族の14,870標本という意味ではない。

一般の主張を支えるのは掲載された解析的証明である。公開版によるとAIによる導出・監査を行ったが、形式証明と人間の専門家による査読は未実施。

次の確認先として、未読の関連論文・学位論文、Chebyshev中心・Mallows距離・凸順序など別用語での先行結果が残る。拡張候補は、平均・分散に幅を許す場合、中心にも同じ分散を課す場合、別の距離を使う場合など。これらは今後の問いであり、既存の式をそのまま移せるとは仮定しない。

## 今後の探索運用

探索先は、既存2件の延長と、別分野の小さな問いから選ぶ。過去の取り組みだけに候補を限定しない。

1. **探索候補を作る。** なぜ余地がありそうかを、等号条件、境界例、仮定の変更、異分野の対応など、具体的な理由で説明する。
2. **先行研究を予備照合する。** 用語の違いも調べ、既知結果と見込まれる部分を早く切り分ける。
3. **一つの命題へ絞る。** 対象、前提、結論、量化、例外を固定する。
4. **反例を探す。** 最小例、退化例、極端なパラメータ、仮定を外した場合を調べる。計算の不一致は保存する。
5. **証明を作り、読み直す。** 計算上の規則性を一般の論証へ移し、必要条件と十分条件、上界と最適性を点検する。
6. **新規性を詰める。** 完成した正確な命題を文献と照合する。既知なら帰属を修正し、残る差分を明示する。
7. **公開可能な単位にまとめる。** 定理、証明、再現コード、引用、限界、失敗と訂正を一緒に残す。

候補の順位は、数学的な有用性、証明へ進める見込み、反例を探す容易さ、新規性を照合する容易さ、計算費用で決める。新規性の確率を根拠なく数値化しない。
