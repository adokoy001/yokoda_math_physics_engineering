capacity: 容量と平均遅延、観測値の上界、有限1状態の等号構成、
          波形の正残差からの容量下界、二指数の容量最小回路。
spectral: 非退化帯域の厳密な上限、有限観測時間の飽和、
          Erlang近似の誤差保証と、その経路族の容量費用。
audit: 独立の解析監査。隠れた漏れ、直接枝、上限と達成の区別。
prior: 一次資料の確認箇所と未取得文献。

範囲: 非負伝導・相反性・正の対角容量・有限安定系。
全波形の結果は一つのクロス応答を固定し、全ポート行列は固定しません。
