# 査読メモ：一つの例外を許す対称性（2026-09-15 第1版）

## 総評

主定理 T1 の証明に穴は見つからなかった。Case A/B/C と mex の最終段はいずれも正しい。帰納仮定を G′ に適用せず、G″ にだけ使っている点も明快。W1 の複製展開、各反例（P₄、容量 (1,1,2) の三角形、z–a–b への w 追加）も手計算で一致した。

埋め込みスクリプトは記載どおり違反なしで再現した（4,165 / 3,330 / 788 件、DP 状態数 130,057）。追加で、2×n 盤（n ≤ 9）の一マス欠損が (n−1) mod 2 になることも確認した。インタラクティブ部は全モードで JS エラーがなく、予測と計算が一致した。

## 指摘事項

### 内容（優先度：高）

1. **「非空のペア群を使う最小の反例」が不正確（第06節）**
   m = 1 で二例外同士を一辺で結んだ 2K₂ は値 0 で、予測の 1 と食い違う。これは辺2本で、P₄（3本）より小さい反例になる。
   → 「最小規模の反例の一つ」とするか、「例外同士が隣接しない場合の最小」と条件を明記する。

2. **「直接代入できる系ではない」に対応する記述がない（第07節）**
   引用符付きだが、表中にこの文言がないため何を受けているのか分からない。
   → 「上表の既知結果へ直接当てはまらないこと」などに言い換える。

### 再現性（優先度：中）

3. **「実行記録」の JSON がどちらのスクリプトの生出力とも一致しない**
   主定理スクリプトは `date` を持たないリストを出力する。重み付きスクリプトは `weighted_verify.json` へ別に書き出す。
   → 「両出力を統合したもの」と注記するか、スクリプトの出力形式を合わせる。

4. **日付表記 `2026 09 15`**
   JSON 内では機械可読性のため `2026-09-15` を推奨する。本文もスペース区切りが意図的でなければ統一する。

5. **主定理スクリプトの `product` の import が未使用**（軽微）

### UI・表示（優先度：低）

6. **「接続を振り直す」ボタンの挙動がラベルと食い違う**
   ランダムモードでは `buildCore()` も呼ばれ、本体まで変わる。
   → ラベルを「盤面を振り直す」にするか、処理を分ける。

7. **W1 の式の `cₘ` が崩れる可能性**
   U+2098 が数式フォントにないと代替フォントで表示され、「cm」に見える（環境依存）。
   → `<sub>` を使う。

8. **モバイルで第06節の P₄ 図が小さすぎる**
   ラベルがほぼ読めない。
   → viewBox の高さを詰めるか、最小サイズを確保する。

9. **ヒーロー図の a₁–z の線が a₃–b₃ 付近を横切る**
   a₃ や b₃ から出た線に見えかねない。
   → 曲線にするか、z の位置を調整する。

## 新規性照合への提案

T1 の本体は「全頂点に負のループ（ペア内辺）を持つ符号付きグラフの 2-lift（二重被覆）」と言い換えられる。並行の辺軌道が正の辺、交差の辺軌道が負の辺に対応する。
